# VectorDB Memory Backend

On-device vector + BM25 hybrid memory powered by the Kylin VectorDataEngine SDK
(`libkysdk-vector-engine-client`). Stores memories in a local `.db` file with
dense embedding + sparse BM25 search, merged via Reciprocal Rank Fusion (RRF).

## Prerequisites

- **Runtime**: `libkysdk-vector-engine-client-dev` debian package installed
- **Build**: `vectordb` Cargo feature enabled
- **Embedding**: An embedding provider (typically `kart-embedding` for on-device,
  or any OpenAI-compatible endpoint)

## Configuration

```toml
[memory]
backend = "vectordb"

# Optional: override defaults
[memory.vectordb]
db_name = "vector"          # resolves to ${workspace_dir}/memory/vector.db
collection = "kylinbot_memory"
embedder = "kart-embedding"  # on-device; also accepts "openai", "custom:URL", etc.
```

All `[memory.vectordb]` fields have defaults — an empty section is valid.

## How It Works

1. **Schema**: A collection with fields `f_key`, `f_content`, `f_category`,
   `f_timestamp`, `f_session_id`, `f_embedding` (dense), `f_sparse` (BM25).
   The sparse vector is auto-generated by the SDK's BM25 FunctionSchema.
2. **Store**: Content is embedded via the configured provider, then inserted
   column-wise. The SDK produces the sparse vector internally.
3. **Recall**: Hybrid search using `hybrid_search_rrf` with a dense ANN request
   + sparse text request, ranked with RRF (k=60). Session ID and time-window
   filters are applied in Rust after retrieval.
4. **Get/List/Forget**: Use SDK query expressions for exact-key lookup and
   filtered scans.

## Graceful Degradation

| Scenario | Behavior |
|---|---|
| SDK library not found | WARN + fall back to `NoneMemory` |
| SDK init fails | ERROR + fall back to `NoneMemory` |
| `vectordb` feature disabled | WARN + fall back to `NoneMemory` |
| NoopEmbedding (dims=0) | WARN + skip collection creation; vector search unavailable |

The process **never crashes** due to SDK unavailability.

## Comparison with Qdrant

| | VectorDB | Qdrant |
|---|---|---|
| Deployment | On-device (local `.db`) | Remote server / cloud |
| Hybrid search | Built-in (SDK BM25 + dense) | Requires separate sparse config |
| Setup | Install debian package | Run Qdrant server + configure URL |
| Network | None | HTTP/gRPC |
| Best for | Air-gapped, offline-first | Multi-instance, cloud deployments |
