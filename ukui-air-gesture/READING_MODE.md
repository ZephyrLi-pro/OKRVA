# 当前阅读挥手模式

K1当前服务使用`AIR_GESTURE_PROFILE=reading`、`AIR_GESTURE_READING_TARGET=reader`，摄像头由`AIR_GESTURE_CAMERA`指定。手势服务与PPT阅读器独立运行，通过D-Bus交互。

```sh
systemctl --user start ukui-air-gesture.service
systemctl --user start riscv-ai-reader.service
```

张开手掌，先在画面中部停稳，等待“已就绪”，再向一侧挥动。**右挥下一页，左挥上一页**。每次有效外挥只计一次；回位不产生反方向事件。每次回到起手位置，等待再次就绪后继续。手部丢失后先回位停稳，不拼接丢失前后的轨迹。

暂时失去就绪时，把完整手掌放在画面中部停稳片刻，程序会重新确认起点；不必反复寻找原来的精确坐标。已经计数的外挥仍需完成回位，在外侧停住不会直接变成下一次动作。

识别使用最新帧，不积累旧帧；过期结果不会触发翻页。横移幅度随手掌宽度调整，允许自然的小幅斜向移动。小幅动作先显示待确认，继续明确外挥或回到起手位置后才计数；手指弯曲收手、无效手形或确认超时会取消，避免结束操作时多翻一页。轻微越界仅在刚刚连续跟踪到完整张开手掌时允许短时延续；新出现、丢失后重现或严重残缺的边缘手形不能直接触发。当前palm/pose模型仍默认各4线程。

翻页保存一个最新目标页。连续挥动时按顺序更新目标页并限制在文档边界，慢渲染期间合并后续目标，不逐条堆积旧按键。程序通过`org.riscv.AIReader1.GetState`取得当前页和阅读器会话，向同一D-Bus唯一所有者调用`GotoPage`，确认实际页码后才记录完成。目标过期或投递失败会取消，不自动重试；阅读器关闭时返回不可用，不转为全局按键。

识别次数、目标页和已确认页分别记录。快速连续挥动时可以跳过中间页，最终页码对应累计目标；复杂页面渲染期间仍可能等待。当前页文字和语音上下文使用阅读器确认的页面，不使用尚未确认的目标页。

桌面小手图标表示手掌可见性，移开后自动隐藏；图标出现不等于外挥或翻页已完成。完整画面仅用于按需校准，可在手动启动前设置`AIR_GESTURE_READING_PREVIEW=1`；已有实例须先停止。关闭大预览不会关闭手势识别或小手反馈。

不保存摄像头图像。当前`AIR_GESTURE_EVENT_LOG`仅记录结构化状态和方向事件。计数初值等校准选项属于程序的诊断能力，当前服务不会加载旧诊断快照。

需要重放漏识别问题时，可临时设置`AIR_GESTURE_TRACE_LANDMARKS`为私有诊断文件路径，记录逐帧关键点坐标、采样时间、结果延迟和判定状态；仍不保存图像。该选项默认关闭，诊断结束后取消。

运行纯单元测试：`python3 -B -m unittest discover -s tests -p 'test_*.py'`。完整场景还需核对真实挥手、PPT页码、当前页文本和语音回答。

## 无手时的资源控制

连续无手两秒后，使用内存中的64×48灰度缩略图检查局部画面变化；场景变化可提前触发手掌检测，静态场景每三秒保留一次完整检测作为兜底。曝光整体变化与少量噪点不会触发完整模型。检测到手后立即恢复原有姿态跟踪；刚丢手时保留原有快速重检，回位与计数状态机不变。缩略图不写入磁盘。

OpenCV预处理限制为一线程，ORT手掌/姿态模型仍按各自配置运行。`recognition_state`中的`palm_model_runs`、`pose_model_runs`、`palm_search_skips`可用于核对实际检测频率。CPU对比应使用整个服务cgroup的CPUUsageNSec差值，避开模型初始化，并确认测量期间没有手。
